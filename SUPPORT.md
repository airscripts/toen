| Version | Status | Support |
| --- | --- | --- |
| 0.1.x | Current first release line | Bug fixes and documentation. |

## Getting Help

Check the [documentation index](docs/README.md), run `cargo toen doctor` for
maintainer diagnostics, and search existing GitHub issues before opening a new
one. Include the platform, Rust version, host CLI version, command, and a
minimal reproducible error. Do not include credentials, private prompts, or
personal data.

## Private Vulnerabilities

Do not open a public issue for an unpatched vulnerability. Contact the
maintainers privately through the repository's configured security reporting
channel and include reproduction and impact details without secrets.
